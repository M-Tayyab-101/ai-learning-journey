These are my original notes from when I was learning:

Running phi3 model using ollama:
1) Downloaded ollama on c folder using browser
2) Chose to keep phi3 on d drive (made a folder there)
3) Set up environment variable and set path
4) Open cmd: ollama serve, ollama run phi3

Setting up open-webui:
1) ollama list (cmd) to check phi3 is there
2) pip install open-webui
3) run open webui: open-webui serve
4) open browser and type: http://localhost:8080

Workflow:
1) Open CMD: ollama serve(Can skip: always running in the background), open-webui
2) open browser and type: http://localhost:8080
